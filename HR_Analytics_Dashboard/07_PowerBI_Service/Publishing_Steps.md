# Publishing Steps – HR Analytics Dashboard

## 1. Project Overview

Project Name: HR Analytics Dashboard using Power BI

Purpose:
To publish the HR Analytics Dashboard from Power BI Desktop to Power BI Service so that users can access and view the report online.

## 2. Tools Required

- Microsoft Power BI Desktop
- Power BI Service
- Microsoft Account
- HR_Analytics.csv Dataset
- HR_Analytics_Dashboard.pbix

## 3. Prerequisites

Before publishing the dashboard:

- Install Power BI Desktop.
- Prepare the HR Analytics dataset.
- Complete data cleaning and transformation.
- Create required DAX measures.
- Design all dashboard visuals.
- Validate KPI calculations.
- Test slicers and filters.
- Save the PBIX file.

## 4. Step-by-Step Publishing Process

### Step 1: Open Power BI Desktop

1. Open Microsoft Power BI Desktop.
2. Open HR_Analytics_Dashboard.pbix.
3. Verify the dashboard visuals.

### Step 2: Sign In

1. Click Sign In in Power BI Desktop.
2. Enter your Microsoft work or school account.
3. Complete the sign-in process.

Note: Publishing availability depends on your account and organizational settings.

### Step 3: Save the Report

1. Click File.
2. Select Save.
3. Save the latest dashboard changes.

### Step 4: Publish the Report

1. Go to the Home tab.
2. Click Publish.
3. Select the destination workspace.
4. Wait for the publishing process to complete.

### Step 5: Open Power BI Service

1. Open the Power BI Service website.
2. Sign in with the same account.
3. Navigate to the selected workspace.
4. Find the published HR Analytics Dashboard report.

### Step 6: Verify the Published Report

Check the following:

- KPI cards display correctly.
- Charts display correctly.
- Department slicer works.
- Filters respond correctly.
- Data values are accurate.
- No unexpected visual errors appear.

## 5. Workspace Details

Workspace Name: HR Analytics Workspace

Report Name: HR_Analytics_Dashboard

Dataset Name: HR_Analytics

Note: These are suggested names. Use the actual workspace and dataset names from your Power BI Service account.

## 6. Sharing the Report

1. Open the published report.
2. Click Share if available.
3. Enter the intended recipients.
4. Select the required permissions.
5. Send the sharing invitation.

Note:
Recipients may need appropriate Power BI licenses or workspace permissions. Do not publish confidential employee information publicly.

## 7. Publishing Validation Checklist

- [ ] Microsoft account signed in.
- [ ] PBIX file saved.
- [ ] Correct workspace selected.
- [ ] Report published successfully.
- [ ] Report opens in Power BI Service.
- [ ] KPI cards verified.
- [ ] Charts verified.
- [ ] Department slicer tested.
- [ ] Access permissions checked.

## 8. Security Considerations

- Share reports only with authorized users.
- Avoid exposing confidential employee data.
- Verify workspace access permissions.
- Configure Row-Level Security (RLS) if different users should see different employee data.
- Never share public links containing confidential HR information.

## 9. Expected Outcome

The HR Analytics Dashboard is available in Power BI Service for authorized users to view and interact with the published report.

## 10. Conclusion

Publishing the HR Analytics Dashboard allows HR teams and stakeholders to access the report online. It supports easier report sharing, centralized access, and better decision-making.
